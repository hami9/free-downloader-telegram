# 🎬 ربات دانلودر همه‌کاره تلگرام (سیستم توزیع‌شده و ضد کرش)

پروژه پیشرفته دانلود از **یوتیوب (با انتخاب کیفیت)**، **اینستاگرام**، **تیک‌تاک**، **توییتر/ایکس** و **پینترست** با معماری توزیع‌شده بر پایه صف پیام (Redis Task Queue) و سیستم کش هوشمند `file_id`.

---

## 🚀 ویژگی‌های کلیدی

1. **پشتیبانی کامل از ۵ پلتفرم پرطرفدار:**
   - 📺 **YouTube:** استخراج لیست رزولوشن‌ها (1080p, 720p, 480p, 360p) + نسخه صوتی (MP3) و ارائه دکمه‌های شیشه‌ای انتخاب کیفیت.
   - 📸 **Instagram:** ریلزها و ویدیوهای پست.
   - 🎵 **TikTok:** دانلود با کیفیت اصلی و بدون واترمارک.
   - 🐦 **Twitter / X:** ویدیوها و گیف‌ها.
   - 📌 **Pinterest:** پین‌های ویدیویی.

2. **سیستم پخش بار و ضد کرش (Load Distribution & Queue):**
   - معماری مستقل **Producer-Consumer** بر پایه Redis.
   - بات هرگز در اثر هجوم درخواست‌ها هنگ یا کرش نمی‌کند؛ درخواست‌ها وارد صف شده و توسط ورکرها پردازش می‌شوند.
   - قابلیت افزایش تعداد پردازشگرها (Horizontal Scaling) تنها با یک دستور:
     ```bash
     docker compose up -d --scale worker=5
     ```

3. **سیستم کش فوق‌العاده هوشمند (Smart Caching):**
   - به محض اینکه یک ویدیو برای اولین بار دانلود شود، `file_id` تلگرامی آن در Redis ذخیره می‌شود.
   - اگر کاربر دیگری همان لینک را درخواست کند، ویدیو در کمتر از ۱۰۰ میلی‌ثانیه مستقیماً از سرور تلگرام برای او ارسال می‌شود (بدون صرف حتی ۱ کیلوبایت از حجم و CPU سرور شما!).

4. **سیستم ضد اسپم و مدیریت ترافیک کاربران:**
   - جلوگیری از ارسال درخواست‌های هم‌زمان متعدد توسط یک کاربر (تک‌تسک هم‌زمان برای هر کاربر).
   - نمایش درصد دانلود و سرعت زنده در پیام تلگرام با محدودسازی ریت ادیت پیام برای جلوگیری از لیمیت تلگرام.

## 🛠 پیش‌نیازها و راه‌اندازی با داکر (ساده‌ترین روش)

### ۱. تنظیم فایل `.env`
ابتدا فایل `.env.example` را کپی کرده و به نام `.env` ذخیره کنید:
```bash
cp .env.example .env
```
سپس توکن دریافتی از @BotFather را در آن قرار دهید:
```env
BOT_TOKEN=123456789:ABCDefghIJKLmnOPQRstuvWXyz
```

### ۲. اجرای پروژه با داکر (Docker Compose)
کافیست در ترمینال دستور زیر را اجرا کنید:
```bash
docker compose up -d --build
```
این دستور به‌طور خودکار:
- پایگاه داده و صف Redis را اجرا می‌کند.
- هسته تلگرام (Bot) را اجرا می‌کند.
- ورکر دانلود (Worker) همراه با آخرین نسخه `yt-dlp` و `ffmpeg` را آماده و فعال می‌سازد.

### ۳. افزایش تعداد ورکرها (افزایش توان پخش بار)
اگر کاربران شما زیاد شدند و صف شلوغ شد، تنها با دستور زیر تعداد ورکرها را به عنوان مثال به ۵ عدد افزایش دهید:
```bash
docker compose up -d --scale worker=5
```

## 📂 ساختار فایل‌های پروژه

```text
├── docker-compose.yml          # تنظیمات اجرای کانتینری ردیس، بات و ورکرها
├── Dockerfile                  # ایمیج اختصاصی با پایتون ۳.۱۲ و ffmpeg
├── requirements.txt            # پکیج‌های پایتونی
├── config.py                   # تنظیمات اعتبارسنجی شده
├── .env.example                # قالب متغیرهای محیطی
├── app/
│   ├── bot.py                  # اینتری‌پوینت اصلی ربات تلگرام
│   ├── handlers/
│   │   ├── start.py            # دستورات /start و /help
│   │   ├── media.py            # تشخیص پلتفرم و ارسال به صف
│   │   └── callbacks.py        # هندل کردن دکمه‌های کیفیت یوتیوب
│   ├── services/
│   │   ├── extractor.py        # استخراج کیفیت‌ها و متادیتای یوتیوب
│   │   ├── downloader.py       # دانلود ایمن با yt-dlp و کانورت ffmpeg
│   │   └── cache.py            # کش کردن file_id ها و لیمیت کاربر
│   └── queue/
│       ├── manager.py          # مدیریت صف Redis و افزودن تسک‌ها
│       └── worker.py           # پردازشگر تسک‌ها و آپلود به تلگرام
```
